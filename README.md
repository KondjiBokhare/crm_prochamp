\# ProChamps CRM - Hardware E-Commerce



Enterprise-oriented Customer Relationship Management system for a hardware e-commerce business.



\## Project Structure



\- `backend/` - Django REST API backend

\- `frontend/` - React frontend

\- `docs/` - Project documentation

\- `tests/` - Testing resources



\## Technology Stack



\- Frontend: React

\- Backend: Django + Django REST Framework

\- Database: PostgreSQL

\- Authentication: JWT

\- Version Control: Git + GitHub
